# Aura Website

Official public showcase site for **Aura**, a native macOS moving-wallpaper and screen-saver app.

The production website is the static site in `docs/`, intentionally separated from the private Aura application repository.

- This repository contains marketing/showcase files only.
- No Aura app source code belongs here.
- No payment credentials, license-signing keys, or private configuration belong here.
- Website changes are checked automatically for broken local links and missing assets.

GitHub Pages URL: https://k1ng-kat.github.io/Aura-Website/
