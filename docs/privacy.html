Privacy

Aura is built around files that stay on your Mac.

This is a plain-language summary of what the current app reads and stores.

Video files

Videos added through Finder remain in their original location. Aura stores a read-only security-scoped bookmark so the sandboxed app can reopen a selected file after relaunch. Aura does not upload user videos.

Smart Visibility

To decide whether a moving wallpaper should pause, Aura reads the on-screen geometry of normal application windows through Core Graphics. It uses window rectangles, layer numbers, and opacity information for this calculation.

Aura does not capture window pixels, take screenshots, read text from other apps, record the screen, or upload window information as part of Smart Visibility.

Apple Wallpapers

The Apple Wallpapers browser reads wallpaper videos and metadata already downloaded by macOS. Aura does not edit, replace, or delete Apple’s wallpaper assets. When sandbox access requires it, Aura asks you to select the relevant folder and stores read-only access.

Screen Saver Match

When Screen Saver Match is enabled, Aura creates a local working copy of the current scene in Aura’s Application Support directory. The Aura Screen Saver companion reads that local copy. Turning Screen Saver Match off removes the synced working video.

Network activity

Aura’s core wallpaper, scheduling, Smart Visibility, Apple-wallpaper discovery, and screen-saver features are designed to work without an Aura server or user account.

Analytics and advertising

The current Aura implementation does not include third-party analytics, advertising SDKs, or tracking SDKs.

Reset

Resetting Aura clears Aura’s scene and settings references. It does not delete your original videos or Apple’s wallpaper files.

Changes

This page will change if Aura’s data handling changes.
