Support

Start with the part of Aura that is giving you trouble.

Aura is still in development. These notes match the current app behavior and will change as the app changes.

Wallpaper Library

If a local video was moved or renamed, add it again from Aura Library so macOS can grant access to the new location.

Why Aura asks for file access →

Smart Visibility

Smart Visibility estimates how much of the desktop is covered using normal window geometry. Adjust the pause and resume thresholds in Aura if it pauses too early or too late.

Schedule

Scenes can use normal clock times or supported solar events. If a solar event looks wrong, check the schedule entry and its before/after offset.

See how scheduling works →

Screen Saver

Use the editor to position elements, then apply the result. Screen Saver Match uses a local working copy so the companion screen saver can read the current Aura scene.

See the editor →

Apple Wallpapers

Aura only sees compatible Apple wallpaper videos that macOS has already downloaded. If nothing appears, download an animated wallpaper in System Settings and rescan.

Reset

Resetting Aura clears Aura’s library references, schedule, and settings. It does not delete your original videos or Apple’s wallpaper files.
