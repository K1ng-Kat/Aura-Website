Support

Help without the maze.

Aura is being built to keep common setup and troubleshooting inside the app. This page covers the main places to start.

▧

Wallpaper library

If a local video is unavailable after it moves, re-add it from Aura Library so macOS can grant access to the file's new location.

Explore Aura features →
◉

Smart Visibility

Smart Visibility uses window geometry rather than screen recording. If behavior feels unexpected, check Aura's Smart Visibility settings and coverage threshold.

Read the privacy details →
▱

Screen Saver Studio

Build the canvas in Aura, preview it live, and apply changes when you're finished. Unapplied edits can be discarded if you leave the editor.

See Screen Saver Studio →
◷

Schedules

Aura can use normal clock times and, with supported features, natural-light events such as sunrise, golden hour, sunset, and twilight.

See scheduling →
▣

Displays

Display behavior can vary with connected monitors and macOS Spaces. Aura includes display-aware controls so you can tune output for your setup.

See display features →
⚙

Reset and recovery

Resetting Aura clears Aura's references and settings. It does not delete your original videos or Apple's wallpaper files.
